# صور المشروع (images/)

حط هنا الصور بهاد الأسماء بالضبط (الصفحة كتستعملهم):

| الملف | الاستعمال | المقاس الأصلي (px) |
|---|---|---|
| `logo.jpg` | لوغو الهيدر | 40 × 45 |
| `product.jpg` | صورة العلبة فالـ Hero + معاينة المشاركة (og:image) | 450 × 650 |
| `lifestyle.jpg` | صورة سيدة تحمل كأساً (قسم علاش بالضبط) | 360 × 665 |
| `olive.jpg` | العلبة وسط أشجار الزيتون | 720 × 950 |
| `usage-1.jpg` | صورة الاستعمال الأولى | 690 × 720 |
| `usage-2.jpg` | صورة الاستعمال الثانية | 720 × 660 |
| `ingredients.jpg` | العلبة محاطة بالمكونات | 720 × 950 |

نصائح:
- حافظ على نفس النسبة (width/height) باش ما يتبدلش التخطيط.
- ضغط الصور (WebP أو JPG بجودة 80) قبل النشر، خصوصاً `product.jpg` لأنها أول صورة كتبان.
- إلا بدلتي الامتداد (مثلاً `product.webp`) بدل المسار فـ `index.html`.
